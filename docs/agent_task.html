⚠️ Avoid Look-Ahead Bias

The current strategy was optimized on 2023-2026 data. To truly validate its predictive power, we need a new agent to recreate it using ONLY 2020-2025 data, then forward-test on 2026.

🎯 Why This Matters

Look-ahead bias is when a strategy is inadvertently optimized on data it will be tested on, making backtest results unrealistically good.

The solution: Have a fresh agent develop the strategy using historical data (2020-2025), then test it on "future" data (2026) that wasn't available during development.

  • Training Period: 2020-2025 (5 years)
  • Forward Testing: 2026 (current year)
  • Goal: Achieve similar performance without knowing 2026 data
